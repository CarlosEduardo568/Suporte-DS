AMB_01

Como abrir uma pasta/projeto corretamente no VS Code?

Nunca abra apenas o arquivo index.html solto. Veja as 3 formas corretas de abrir a pasta raiz do projeto para o CSS, JS e Live Server funcionarem.

  1. Pelo menu: clique em File > Open Folder... e selecione a pasta inteira do projeto.
  2. Por atalho: pressione Ctrl + K e depois Ctrl + O.
  3. Pelo terminal: entre na pasta do projeto e digite code . (o ponto significa pasta atual).
[DICA] Se aparecer "Do you trust the authors?", clique em Yes, I trust the authors.

Principais atalhos do VS Code para programar mais rápido

Domine os atalhos de teclado mais usados por devs: duplicar linha, múltiplos cursores, paleta de comandos e terminal integrado.

  • Paleta de comandos Ctrl + Shift + P
  • Duplicar linha Alt + Shift + ↓
  • Multi-cursor (próxima igual) Ctrl + D
  • Comentar / descomentar Ctrl + ;
  • Abrir/fechar terminal Ctrl + '

WIN_03

Principais atalhos do Windows no laboratório

Como dividir a tela entre VS Code e navegador, usar o histórico de copiar/colar, tirar print seletivo de erros e corrigir teclado desconfigurado.

  • Dividir tela (VS Code + Navegador) Win + ← / →
  • Histórico de área de transferência Win + V
  • Print recortado de erro Win + Shift + S
  • Alternar janelas rápido Alt + Tab
  • Trocar idioma do teclado (ABNT2) Alt + Shift

Como logar na conta @aluno.educacao.sp.gov.br?

Entenda o padrão do e-mail institucional com o seu RA, como fazer o primeiro acesso no Google/Teams e como recuperar a senha na SED.

0000 + [RA_com_digito] + sp@aluno.educacao.sp.gov.br

  1. Acesse sed.educacao.sp.gov.br para consultar seu RA ou redefinir senha.
  2. Em "Esqueci a Senha", escolha o perfil Aluno e informe RA, data de nascimento e nome da mãe.
  3. Use o e-mail completo para entrar no Google Classroom, Microsoft Teams e solicitar o GitHub Student Pack.

WEB_05

Como rodar meu site HTML no navegador com Live Server?

Chega de ficar apertando F5 o tempo todo. Instale o Live Server no VS Code e veja suas alterações em tempo real a cada Ctrl + S.

  1. Abra a aba de extensões com Ctrl + Shift + X.
  2. Pesquise por Live Server (autor: Ritwick Dey) e clique em Install.
  3. Clique com o botão direito no arquivo index.html e selecione Open with Live Server (ou clique em Go Live no canto inferior direito).

FIX_06

Erro de permissão no PowerShell ou terminal travado no lab

Apareceu PSSecurityException ou "running scripts is disabled"? Veja como trocar o terminal para Git Bash ou liberar o escopo do usuário.

  1. Opção mais rápida: no terminal do VS Code, clique na setinha ao lado do botão + e escolha Git Bash ou Command Prompt (cmd).
  2. Opção no PowerShell: execute o comando abaixo (não exige administrador):

Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
